# Agentic Platform Lab

A four-week, public learning project: a .NET API on AKS, delivered through GitHub Actions with Entra workload identity, and worked on by AI agents that open, fix and review pull requests. Built spec-first with GitHub Spec Kit, measured with agent evals and DORA / DX Core 4 metrics.
